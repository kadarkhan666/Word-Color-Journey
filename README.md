# Word Search Game

A colourful, playful, and relaxing Word Search Puzzle application rewritten in React with TypeScript, Vite, and Tailwind CSS, featuring progressive cartoon picture reveals, 100 handcrafted progression levels, and daily puzzle challenges.

## Features

- **100 Playable Levels**: Handcrafted progression from beginner (4x4, 5x5) to master (8x8) across themes like Animals, Nature, Fruits, Toys, Oceans, Cosmos, Gardens, and Adventure.
- **Progressive Picture Reveals**: 10 vector cartoon illustrations (Apple, Cat, Flower, Sun, Fish, Rainbow, Balloon, Butterfly, Avocado, Rocket) that color in with an animated pencil marker as you find words.
- **Daily Puzzle Mode**: Deterministic daily word search puzzles seeded by current date, complete with day streaks and completion tracking.
- **3 Color Markers**: Switch between Bubblegum Pink, Sunshine Yellow, and Mint Sky highlighters.
- **Intuitive Touch & Drag Selection**: Drag or swipe in horizontal, vertical, or diagonal directions with visual line ribbons.
- **Celebration Dialog**: Confetti celebration, golden star ratings, and smooth transitions upon solving each puzzle.
- **Progress Persistence**: Automatically saves unlocked levels, completed stars, and daily streaks in `localStorage`.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
